# เว็บเซอร์ไพรส์แฟนคลับ

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `js/config.js` | **ตั้งค่าทั้งหมด** รหัส ชื่อแชท ข้อความ รูปโปรไฟล์ รูปโพลารอยด์ เพลง |
| `index.html` | โครงหน้าเว็บ (หน้ารหัส โทรศัพท์ ฯลฯ) |
| `css/style.css` | สีและหน้าตา เรียงตามหน้า |
| `js/passcode.js` | หน้าใส่รหัส |
| `js/phone.js` | หน้าจอล็อก และแชทข้อความอวยพร |
| `js/ending.js` | นับถอยหลังทำลายตัวเอง และระเบิดหัวใจ |
| `js/board.js` | หน้ากระดานดำ: คำถามขึ้นทีละข้อ (ตั้งที่ `board` ใน config) |
| `js/gallery.js` | หน้าโพลารอยด์ 20 รูปกระจาย และตัวดูรูปใหญ่ |
| `js/popups.js` | Alert "เปิดอ่าน" กล่องข้อความเด้งเต็มจอ (กดดู/ลากย้ายได้) และปุ่ม "กดตรงนี้สิ" |
| `js/audio.js` | เสียงเอฟเฟกต์ เพลง ปุ่มปรับเสียง (ความดังเริ่มต้นแก้ที่ `VOL`) |
| `assets/` | รูปทั้งหมด (โปรไฟล์ สติกเกอร์ ไอคอนช่องรหัส รูปโพลารอยด์) และโฟลเดอร์เพลง |

## แก้อะไรได้ง่ายๆ
- **เปลี่ยนรหัส / ข้อความ / ชื่อ**: แก้ `js/config.js`
- **เปลี่ยนรูปโปรไฟล์**: ใส่ไฟล์ใหม่ทับชื่อเดิมใน `assets/avatars/` หรือเปลี่ยนชื่อไฟล์ใน config
- **เปลี่ยนรูปโพลารอยด์**: ใส่รูปสี่เหลี่ยมจัตุรัส (เช่น 480×480) ไว้ใน `assets/photos/` แล้วแก้รายการ `photos` ใน `js/config.js` (เพิ่ม/ลดจำนวนได้ ตอนนี้เป็นรูปตัวอย่าง 20 รูป)
- **ใส่เพลงของตัวเอง**: วางไฟล์ใน `assets/music/` แล้วตั้ง `music` ใน config (ใช้เพลงที่มีสิทธิ์ใช้เท่านั้น)
- **ตัวเลข 25+ บนแจ้งเตือน**: แก้ใน `index.html` (ค้นหา `25+`)

## เปิดดู / เผยแพร่
- ดับเบิลคลิก `index.html` เปิดดูในเบราว์เซอร์ได้เลย
- ส่งให้คนอื่นดู: อัปโหลดทั้งโฟลเดอร์ขึ้นโฮสต์ฟรี เช่น Netlify Drop (ลากโฟลเดอร์ไปวาง) หรือ GitHub Pages
- ทดสอบบนมือถือ: เปิดลิงก์ที่โฮสต์แล้วจากมือถือ
